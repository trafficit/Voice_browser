# Голосовой помощник для ребёнка (Docker, Ubuntu 20.04)

Слушает микрофон, офлайн распознаёт русскую речь (Faster-Whisper) и управляет
Chromium (YouTube Kids) через Selenium. Активируется словом «запустись»
(или «запусти»/«запускай»/«включись») и выключается словом «остановись»
(или «выключись»/«хватит») — не реагирует на звук телевизора/фоновую речь,
пока не активирован.

Собрано на другой машине (Windows) — эту папку нужно перенести на сам
Ubuntu-компьютер и запускать уже там, потому что нужен доступ к живому X-серверу,
микрофону и колонкам этой машины.

## 1. Перенос на Ubuntu ПК

Скопируйте всю папку `voice-browser-kids` на Рабочий стол Ubuntu-машины, например
через флешку, `scp` или общую сетевую папку:

```bash
scp -r voice-browser-kids user@ubuntu-pc:~/Desktop/
```

Дальше все команды выполняются **уже на самом Ubuntu ПК**.

## 2. Установка Docker (если ещё не установлен)

```bash
sudo apt update
sudo apt install -y docker.io docker-compose-plugin
sudo systemctl enable --now docker
sudo usermod -aG docker $USER   # затем перелогиньтесь
```

## 3. Настройка `.env`

```bash
cd ~/Desktop/voice-browser-kids
cp .env.example .env
echo "DISPLAY=$DISPLAY"
echo "XDG_RUNTIME_DIR=$XDG_RUNTIME_DIR"
```

Впишите полученные значения в `.env`. Обычно `DISPLAY=:0`,
`XDG_RUNTIME_DIR=/run/user/1000`.

## 4. Разрешить контейнеру рисовать окно на экране

Перед каждым запуском (или один раз при автозагрузке, см. ниже) на хосте нужно
выполнить:

```bash
xhost +local:docker
```

Без этого Chromium не сможет открыть окно на дисплее хоста.

## 5. Добавьте любимые мультики и фильмы ребёнка (по желанию, но рекомендуется)

Откройте `app/config.yaml` и впишите проверенные вами ссылки:

```yaml
favorites:
  "синий трактор": "https://www.youtubekids.com/watch?v=..."
  "маша и медведь": "https://www.youtubekids.com/channel/..."
  "моана": "https://hd.kinopoisk.ru/film/..."
  "миньоны 1": "https://okko.tv/movie/..."
  "монстры на каникулах": "https://ivi.ru/watch/..."
```

Это даёт ребёнку возможность включать конкретные любимые мультики/фильмы по
названию без обращения к живому поиску. Свободный поиск (`strict_whitelist:
false` по умолчанию) остаётся доступен через фразы "найди...", "включи...", но
при желании максимальной безопасности поставьте `strict_whitelist: true` —
тогда будут доступны только пункты из `favorites`.

**Про фильмы (Моана, Миньоны, Монстры на каникулах и т.п.):** вписывайте сюда
ссылки только с легальных сервисов, где у вас есть доступ к контенту
(Кинопоиск HD, Okko, IVI, Wink, Google Play/Apple TV, YouTube-аренда, либо ваш
собственный Plex/Jellyfin с уже купленными дисками/цифрой). Пиратские сайты
(hdrezka и подобные) сюда специально не встроены — это распространение
контента без лицензии, юридический риск, плюс на таких сайтах много
навязчивой рекламы и небезопасных всплывающих окон, что для детского
использования особенно плохо. Большинство легальных сервисов требуют один раз
залогиниться в открывшемся окне Chromium — сессия сохранится в docker-volume
`chrome-profile` и повторно логиниться не придётся.

## 6. Сборка и запуск

```bash
docker compose build
docker compose up -d
docker compose logs -f
```

При самом первом запуске Faster-Whisper скачает модель (~500 МБ для `small`) —
для этого нужен интернет один раз. Дальше модель хранится в docker-volume
`whisper-cache` и распознавание работает полностью офлайн.

## 7. Автозапуск при включении компьютера

Чтобы дочке не нужно было ничего делать руками:

**a) Docker-контейнер** уже настроен на `restart: unless-stopped` — после
`docker compose up -d` он будет сам подниматься при перезагрузке, если запущен
демон Docker (шаг `systemctl enable docker` в п.2 это обеспечивает).

**b) `xhost +local:docker`** нужно выполнять при каждом входе в графическую
сессию (это ограничение X11, а не Docker). Добавьте автозапуск через:

```bash
mkdir -p ~/.config/autostart
cat > ~/.config/autostart/voice-browser-xhost.desktop <<'EOF'
[Desktop Entry]
Type=Application
Name=Voice Browser xhost
Exec=xhost +local:docker
X-GNOME-Autostart-enabled=true
NoDisplay=true
EOF
```

После этого при каждом входе в систему право на доступ к экрану будет выдаваться
автоматически, а сам ассистент поднимется вместе с Docker.

## Как это работает: старт/стоп, а не кодовое слово на каждую фразу

1. Ребёнок говорит **«запустись»** — ассистент активируется (короткий высокий
   сигнал в подтверждение) и дальше слушает команды свободно, без повторения
   кодового слова.
2. Дальше можно просто называть, что включить: «включи синий трактор», «найди
   мультик про машинки», «пауза», «погромче», «весь экран», «назад», «домой».
3. Когда всё, ребёнок говорит **«остановись»** — ассистент перестаёт
   реагировать на речь (низкий сигнал) и снова ждёт «запустись». Если в
   активном режиме 10 минут подряд тишина — ассистент сам остановится (можно
   поменять через `AUTO_STOP_AFTER_S` в `.env`).

По умолчанию понимает несколько форм: «запустись»/«запусти»/«запускай»/«включись»
для старта и «остановись»/«выключись»/«хватит» для стопа — сработает любое из
них. Список настраивается в `app/config.yaml` (`start_word`/`stop_word`, через
запятую) или через `.env` (`START_WORD`/`STOP_WORD`).

### Словарь команд (после «запустись»)

- «включи синий трактор» / «моана» / любой пункт из `favorites`
- «найди мультик про машинки» — поиск на youtubekids.com
- «пауза» / «играй» — пауза/продолжить
- «погромче» / «потише»
- «весь экран»
- «назад»
- «домой» / «открой браузер» — вернуться на youtubekids.com
- «остановись» — выключить ассистента

## Проверка микрофона/звука внутри контейнера

```bash
docker compose exec voice-browser python3 -c "import sounddevice as sd; print(sd.query_devices())"
```

Если список пуст или падает с ошибкой — проверьте, что `XDG_RUNTIME_DIR` в `.env`
совпадает с `echo $XDG_RUNTIME_DIR` на хосте, и что на хосте вообще работает
PulseAudio/PipeWire-pulse (`pactl info`).

## Частые проблемы

- **Чёрное окно / контейнер не открывает Chromium** — забыли `xhost +local:docker`,
  либо `DISPLAY` в `.env` не совпадает с хостовым.
- **Нет звука с микрофона** — проверьте `XDG_RUNTIME_DIR`, убедитесь что
  `/run/user/<uid>/pulse/native` существует на хосте (`ls $XDG_RUNTIME_DIR/pulse`).
- **`PortAudioError: Invalid sample rate`** — устройство не поддерживает частоту
  из `AUDIO_SAMPLE_RATE` (по умолчанию 48000) напрямую. Попробуйте `44100` в
  `.env` и `docker compose up -d`.
- **Ассистент слушает не тот микрофон** (например встроенный вместо USB) —
  посмотрите точные имена устройств в `docker compose logs` (список выводится,
  если авто-поиск по `AUDIO_DEVICE_MATCH` не нашёл совпадение) и впишите в
  `.env` часть точного названия вашего микрофона.
- **Распознавание медленное** — смените `WHISPER_MODEL` в `.env` на `base` или
  `tiny` и пересоздайте контейнер (`docker compose up -d --build`).
- **Ложные срабатывания на звук из мультфильма/ТВ (в активном режиме)** —
  смените `START_WORD`/`STOP_WORD` на более редкие слова, уменьшите
  `AUTO_STOP_AFTER_S`, чтобы ассистент сам засыпал быстрее, либо не забывайте
  говорить «остановись» после просмотра.
